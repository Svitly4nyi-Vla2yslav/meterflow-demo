# MeterFlow screenshots

Add the final recruiter-facing screenshots to this directory with these exact filenames:

- `01-login.png`
- `02-dashboard.png`
- `03-project-create.png`
- `04-project-detail.png`
- `05-tasks.png`
- `06-documents.png`
- `07-analytics.png`
- `08-tech-stack.png`
- `09-profile.png`

Recommended capture settings:

- 1440–1600 px desktop width
- use clean application state with realistic demo data
- hide browser developer tools
- crop unnecessary browser chrome if possible
- never expose passwords, JWT tokens, database URLs, private e-mail addresses, or other secrets
- prefer PNG or WebP
- keep one consistent viewport and visual scale across screenshots

The root README references these paths directly, so GitHub will render each screenshot automatically once the image files are added.
